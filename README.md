## 📖 About

🔹 **Skyrim — SkyCraft** is a powerful tool built to help you overhaul Skyrim's smithing and crafting system with realistic material requirements and new crafting stations. SkyCraft introduces intermediate crafting materials, pattern-based creation, and specialized forge stations for a deeper smithing experience.

🔸 Whether you're a seasoned professional or just getting started, **Skyrim — SkyCraft** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Skyrim modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Material Tiers | New intermediate materials like ingot alloys and refined leather |
| Crafting Patterns | Weapons and armor require patterns that must be found or purchased |
| Specialized Stations | Jeweler's bench, tanning rack upgrades, and artisan forges |
| Vanilla Integration | All vanilla crafting remains available alongside the new system |
